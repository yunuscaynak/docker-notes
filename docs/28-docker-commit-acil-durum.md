## 28. Docker Commit (Acil Durum)

Calisan container'in anlik halinden image olusturur.

### Komut

```bash
docker commit my-app my-app:backup
```

### Ne zaman kullanilir

- Acil yedek almak istediginde
- Gecici bir snapshot gerektiginde

### Not

Kalici ve duzenli yontem yine Dockerfile ile build almaktir.
