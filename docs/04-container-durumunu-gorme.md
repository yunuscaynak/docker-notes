## 4. Container durumunu gorme

Container calisiyor mu, durdu mu buradan kontrol edilir.

### Temel komutlar

Sadece calisanlari gormek icin:

```bash
docker ps
```

Calisan + duran tum container'lari gormek icin:

```bash
docker ps -a
```

### Hangi durumda kullanilir

- `docker run` sonrasi acildi mi kontrol etmek icin.
- Hata alip duran container'i bulmak icin.
